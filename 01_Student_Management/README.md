# Student Management

Open this folder in VS Code. Install a C++17 compiler (GCC/MinGW-w64).

Windows PowerShell:
```powershell
g++ -std=c++17 -Wall -Wextra main.cpp -o app.exe
.\app.exe
```

Linux/macOS:
```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o app
./app
```

Data is saved automatically in the current working directory and loaded on restart. Use unique IDs. Names may contain spaces. Choose 0 to exit.
