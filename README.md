# C++ Internship Projects

Three independent console applications implementing the supplied task requirements:

1. Student Management: add, update, delete and display persistent student records.
2. Bank Management: create accounts, deposit, withdraw and check balances using an Account class and persistent records. Currency is stored as integer paise.
3. Library Management: books, members, issue/return and case-insensitive title/author searches with persistent records.

Extract the ZIP first. Each project has main.cpp, common.hpp, README.md and a Windows run.bat. Use each project folder as your working directory. A C++17 compiler is required; binaries are not included.

These are newly created educational implementations. Bank storage is a local text file without encryption or authentication; use fictional customer data. It is a banking simulation, not a production banking system. File writes are checked, but the applications are intended for one user/process at a time. Do not manually edit generated data files while running.
